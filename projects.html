Smart Fridge System

AI-assisted inventory capture for a shared refrigerator workflow.

Time Jan 2026 - Mar 2026 • Stack Linux / C++ / YOLO • Role Team Lead

This project focused on turning a refrigerator into a small embedded vision system that could observe activity at the door, capture an image only when relevant movement occurred, and pass that image into an object-detection pipeline. The goal was to reduce manual tracking and provide a more reliable view of what food was actually available.

I led a five-person team through requirements definition, pipeline planning, and system integration. We broke the problem into sensing, image capture, inference, and item-state reporting so that each layer could be tested independently before end-to-end integration.

The resulting system combined motion-triggered capture with YOLO-based classification to identify food items automatically. A strong part of the work was not just getting inference to run, but shaping the surrounding workflow so the hardware behavior, software timing, and output format all fit together as one coherent system.
