# Resource provenance

The current portfolio HTML, CSS, JavaScript and `images/projects/*.svg` concept diagrams were rewritten for this repository. The diagrams illustrate only the supplied project descriptions; they are not measured waveforms, actual implementation diagrams, or screenshots.

The previous site used **Strata by Pixelarity** (pixelarity.com, hello@pixelarity.com; license: https://pixelarity.com/license). Original template notices remain in the preserved `_pgbackup/` files. Those files and original photographs have not been removed or relicensed. The new public pages do not load the old template, jQuery, Poptrox, Pinegrow Interactions, or Font Awesome.

Unused Font Awesome font files and their original stylesheet are retained as historical resources. Font Awesome Free 5.15.4: https://fontawesome.com/license/free — icons CC BY 4.0, fonts SIL OFL 1.1, code MIT. The stylesheet retains its original license notice.

The avatar and UW logo were already present in the repository. University marks remain the property of their respective owners. Add an appropriately sourced Georgia Tech mark when available; no third-party logo was downloaded for this redesign.
